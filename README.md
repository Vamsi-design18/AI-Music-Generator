# AI-Music-Generator
AI Music Generator using Python and Music21 that processes MIDI files, extracts notes and chords, and generates new MIDI music compositions.
## Overview
This project generates music from MIDI datasets using Python and Music21.

## Features
- MIDI preprocessing
- Note extraction
- Music generation
- MIDI output creation

## Technologies Used
- Python
- Music21
- MIDI Dataset

## Output
generated_music.mid
